# سكّرنا وعي — بخطوة وعي نواجه السكري

عرض تفاعلي توعوي عن داء السكري، كلية الطب بجامعة أم القرى بالتعاون مع إدارة العمل التطوعي والمسؤولية المجتمعية.

## الملفات
- `index.html`: العرض كاملًا (التصميم والأنشطة ونص المتحدث).
- `assets/`: الشعارات وخط ثمانية. ارفع المجلد كما هو.
- `.nojekyll`: يجعل GitHub ينشر الملفات كما هي.
- `src/`: ملفات المصدر للتعديل. بعد أي تعديل شغّل `py -3 src/build.py` لإعادة بناء `index.html`.

## الرفع على GitHub Pages
1. أنشئ مستودعًا جديدًا (مثلًا `Sukkarna-Wa3i`).
2. **Add file → Upload files**، واسحب: `index.html` و`assets` و`.nojekyll` و`README.md` (و`src` إن أردت).
3. **Commit changes** على `main`.
4. **Settings → Pages → Deploy from a branch → main / (root) → Save**.
5. بعد دقائق يظهر الرابط: `https://<اسم-حسابك>.github.io/Sukkarna-Wa3i/`

## طريقة العرض
- «التالي» يكشف خطوات الشريحة واحدة واحدة، ثم ينتقل.
- لوحة المفاتيح: ← أو Space التالي، → السابق، F ملء الشاشة، N نص المتحدث، W عجلة الأسئلة، Esc إغلاق.
- يعمل مع ريموت العروض (PageUp / PageDown).
- لفتح شريحة معيّنة: أضف رقمها للرابط، مثل `#6`.
